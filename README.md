# Introduccion

Primera pagina web del bootcamp de ManzDev. Todos los recursos utilizados fueron descargados de la pagina oficial. [ManzDev](https://manz.dev/)

## Dia 1 - Terminal

1. Utilizar la terminal para crear las carpetas donde se guardara todos los proyectos.
2. Organizar los archivos utilizando los comandos `mv` y `cp`.
3. Instalar y configurar el Visual studio code.
4. Creacion y uso de script para facilitar las tareas de creacion de archivos.

## Dia 2 - Fundamentos

> Aunque esta fase sea de fundamentos `JavaScript` no ha sido utilizado en este proyecto.

## Dia 3 - Control de proyecto

- Instalacion de `NodeJS` y `pnpm`
- Creacion de la estructura del proyecto con su carpeta de trabajo
- Inicializando el proyecto con `pnpm` utilizando el modulo ESM.

> [!TIP]
> Para crear un proyecto con `pnpm` utilizando module **ESM** `pnpm init --init-type module`. Para mas informacion revisar la pagina oficial de [pnpm](https://pnpm.io/cli/init)

- Instalacion de las devDependencias `servor`, `oxlint`, `oxfmt` y `stylelint`

> [!IMPORTANT]
> Las reglas utilizadas de todos los linters son las **POR DEFECTO**. Para mas informacion sobre las reglas [oxlint](https://oxc.rs/docs/guide/usage/linter.html), [oxfmt](https://oxc.rs/docs/guide/usage/formatter.html), [stylelint](https://stylelint.io/user-guide/get-started)

- Instalacion de git y creacion de una keygen SSH

> [!WARNING]
> Por tema de seguridad se recomienda utilizar el Protocolo SSH en lugar de HTTPS. Para mas informacion sobre las claves [SSH](https://terminaldelinux.com/git/introduccion/configuracion-github/).

- Instalacion de la devDependencias y creacion del script `gh-pages`

## Dia 4 - Inteligencia Artificial

- Creacion de SKILL y Agents con `OPENCODE` 
- Estructura de proyecto creada con Opencode utilizando los Agents
- Creacion de la imagen [banner.jpg](https://github.com/ElDavih/landing-page-bootcamp/blob/main/src/assets/images/banner.jpg) utilizando Gemini.
- Creacion y modificacion de los meta tags de HTML utilizando Opencode

## Dia 5 - Lenguaje HTML

- Creacion de etiquetas generales de HTML
- Utilizar etiquetas de multimedias
- Solucionar las sopas de div usando la semantica de HTML. 
- Uso de HTML Semantico `section`, `article`, `header`, entre otros.

> [!TIP]
> Si quieres saber mas sobre las etiquetas html aqui hay una [tabla periodica de HTML](https://lenguajehtml.com/html/introduccion/tabla-periodica-html5/)

## Dia 6 - Bases CSS

- Aprender sobre el modelos de cajas
- Utilizar esquemas de colores `rgb`, `hexadecimal`, entre otros.
- Uso de linear gradient para usarlo en fondo con `background-image`
- Creacion y uso de las variables de css
- Integracion de las tipografias 
- Uso del CSS Nesting

## Dia 7 - Layouts CSS

- Uso de flexbox y Grid.
- Uso del position `relative`, `fixed`, `absolute` y `sticky`.
- Utilizar el `@starting-style` para evitar los saltos.
- Keyframes, ritmo, animacion al pasar el cursor sobre los elementos de la pagina.
