Bootcamp ManzDev

En este bootcamp GRATUITO respetamos siempre una filosofía muy concreta.

Requisitos

  • Sistema operativo: Trabajaremos con Windows, pero realmente estaremos usando un ecosistema Linux con WSL (Linux dentro de Windows). Si tienes otro sistema operativo, no cambiará demasiado.
  • ¿Qué equipo necesito?: En general, casi cualquier sistema sirve, pero algunos pueden ser muy lentos. Mi recomendación: CPU i5 con 8-16GB de RAM para una experiencia fluida. Si te interesa trabajar con IA local (gratis y sin necesitar Internet) una muy buena GPU (gráfica) y mínimo, 32GB de RAM.
  • Conocimientos previos: El curso arranca orientado a alumnos sin conocimientos de programación. Sin embargo, es un curso técnico intensivo, por lo que se recomienda tener base tecnológica e indagar un poco antes empezarlo para poder seguirlo mejor.

Contenido del bootcamp

Terminal

En esta primera clase vamos a preparar nuestro entorno de desarrollo, utilizando Linux en Windows mediante WSL y aprendiendo a personalizar la terminal y sus comandos. ¡Vamos allá!

Ver slides

Control de proyecto

En esta clase vamos a aprender a utilizar un gestor de paquetes (pnpm), a instalar Node (u otras herramientas) de una forma práctica y actualizable, configurar y utilizar un linter y formateador moderno (oxc), aprender las nociones básicas de Git y creación de repositorios de GitHub, así como automatizar acciones desde una terminal y desplegar en GitHub Pages. ¡Vamos allá!

Ver slides

Fundamentos

En esta clase veremos los fundamentos de programación y del código Javascript. Todavía no vamos a sentarnos a escribir código, primero hay que entenderlo, saber como guardamos la información, que estructuras hay para guardar datos y puntos importantes, incluso para gente que ya sabe programar, es ajena a Javascript o sólo utiliza Typescript (sin saber a que transpila).

Ver slides

Inteligencia Artificial

En esta clase vamos a entender que es realmente la Inteligencia Artificial, los LLM y ciertos conceptos importantísimos. Además, aprenderemos a utilizar la herramienta OpenCode para utilizar agentes al programar, usar Ollama para tener un CHATGPT local gratis sin necesidad de Internet, y aprenderemos a usar ComfyUI para IA generativa de imágenes con modelos de Stable Diffussion o Qwen Image.
